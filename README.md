## 深度1：巴克莱：自动化3.0时代开启 人形机器人市场10年后或达2000亿美元

巴克莱将人形机器人定义为“自动化3.0”，并给出未来十年市场达2000亿美元的量级判断，这实质上是在宣告：这个赛道已从实验室的技术原型阶段，正式进入资本驱动的产业化前夜。关键不在绝对数字的精确性，而在于顶级投行开始用量化模型测算一个尚未大规模商业化的品类——这意味着二级市场的估值锚正在形成。

从产业链视角看，这2000亿美元目标将重新分配价值流向。人形机器人产业链上游是精密零部件（谐波减速器——机器人关节的核心传动部件，决定运动精度和寿命，目前日本哈默纳科占全球份额超60%；力矩传感器——让机器人感知力的元件，成本占比约15%）、中游是本体制造和系统集成、下游应用覆盖制造、物流和家庭服务。当前中国企业在谐波减速器和力矩传感器领域的国产化率仍不到30%，上游精密零部件的议价权牢牢握在海外供应商手中。这意味着，在市场快速膨胀的早期阶段，上游零部件企业更可能率先兑现业绩，而中游本体制造商将面临更长的亏损周期和高烈度竞争。

具体数字方面，巴克莱给出的是“10年后”（约2036年）“2000亿美元”的远期规模，但报告未披露具体的年复合增长率假设和拆分口径（软件/硬件/服务占比），后续需关注其完整研报对产业链各环节的细分预测。结合当前全球头部人形机器人公司（如特斯拉Optimus、傅利叶智能）仍处小批量试产阶段、单价普遍在数十万美元量级的现状，要达到2000亿美元规模需要成本下降90%以上，这将直接考验中国零部件企业的降本能力——谁能先把谐波减速器成本做到日本同类产品的三分之一，谁就可能吃到最大的份额。
