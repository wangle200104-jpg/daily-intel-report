## 深度文章2：博通指引折射的AI定制芯片叙事裂缝

**来源**：MSN | **领域**：AI芯片/半导体

博通AI相关营收指引未达买方预期，触发了市场对定制AI芯片商业模式的重新审视。这笔业务主要来自为谷歌等客户定制TPU（张量处理器——专为机器学习推理和训练设计的芯片，与英伟达通用GPU形成路线之争），其增长节奏的放缓，暗示大型云厂商自研芯片的放量速度已从脉冲式爆发转为渐进式爬坡。

在产业链上，博通扮演的是ASIC设计服务与IP集成的角色，位于中游。上游是博通与之深度捆绑的晶圆代工和先进封装产能，以及它自有的高速SerDes IP（串行解串器知识产权——决定芯片间互联带宽的核心模块）。下游客户高度集中，意味着某一客户需求节奏的变化会直接放大营收波动。这次指引偏软，核心问题在于谷歌等客户逐步将部分定制能力内化，或者当前一代TPU的部署密度已达到阶段性饱和，需要等待下一代架构与配套的光互连设施就绪。

与英伟达的通用平台路线相比，定制ASIC虽然能获得极致能效比，但也牺牲了跨场景迁移的灵活性。当AI工作负载快速演化，从大语言模型转向多模态和具身智能推理时，定制芯片可能面临重设计周期长的劣势。赢家不会由一条路线单独锁定，但受短期业绩指引冲击最直接的，是收入集中度最高的那一个。博通跌幅带动整个芯片板块下挫，说明市场开始重新区分“AI叙事”里的结构性赢家与周期性暴露。
