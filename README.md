## 深度文章1：CoWoS扩产潮向下游蔓延，封装材料环节迎来国产替代窗口

**来源**：集微网 | **领域**：先进封装CoWoS

英尔捷半导体在苏州工业园区启动的高端芯片封装项目，指向一个正在发生的产业迁移——CoWoS（Chip on Wafer on Substrate，将不同芯片像乐高一样堆叠在硅晶圆再封装到基板上的技术，直接决定AI芯片算力密度）产能紧缺已从台积电向下游供应链传导。

这个总投资5亿元、规划年产50亿颗高端芯片的项目，在半导体封装产业链上属于中游环节。封装产业链清晰分为三层：上游是封装材料与设备（环氧塑封料、锡球、湿电子化学品、封装基板等），中游是封装代工厂（OSAT，外包半导体封测企业），下游是芯片设计公司和终端品牌。英尔捷切入的正是中游封装环节，产能目标50亿颗的规模说明其定位并非实验室样品，而是瞄准了规模化量产——这是国内封测厂商从传统封装向先进封装升级的明确信号。

CoWoS产能瓶颈的根源在产业链上游：台积电的封装产能受制于中介层（连接芯片与基板的“转接板”）精密度和关键材料供应，而这两点恰恰是国产替代的突破口。飞凯材料此次同步披露的功能型湿电子化学品（高纯度的清洗液、蚀刻液，用于晶圆表面微米级加工）和EMC环氧塑封料（芯片的“盔甲”，起保护和散热作用），正是封装上游的核心耗材。英尔捷这类封测厂商扩产，将为上游材料商打开出货通道。

竞争格局正在分化。一方面，台积电、英特尔通过玻璃基板（用玻璃替代传统树脂作为封装基础材料，解决超大芯片的热翘曲问题）等技术创新向上游延伸；另一方面，国内封装环节的投资密集落地，从通富微电到英尔捷，产能建设速度远超材料认证周期。这意味着短期最受益的是封测环节本身，而材料环节仍需通过客户验证的漫长周期，但长期看封装厂国产化将倒逼材料国产化。

**今日启示**：关注封装材料厂商的客户导入进度——能率先进入通富微电这类头部封装厂供应链的环氧塑封料或湿电子化学品企业，将获得确定的增量订单。
