## 深度文章1：英伟达Rubin CPX重构AI推理算力范式

**来源**：SemiAnalysis | **领域**：半导体/算力架构

英伟达发布的Rubin CPX加速器，本质上是一次针对AI推理工作负载的算力结构重新定价。该架构将单芯片的算力堆叠推向极致，刻意强调计算浮点能力而弱化内存带宽，直接对标大模型推理中的“预填充”阶段。

这一变化并非微调，而是对数据中心机架结构的底层重构。在Transformer模型运行中，预填充阶段负责一次性处理输入文本的全部上下文，计算密度极高，却对内存带宽不敏感——这与传统训练或逐字生成阶段截然不同。当前数据中心普遍采用的Hopper架构GPU（英伟达上一代主力芯片），其内存带宽与算力比例是为“全能型”负载设计的，结果是大量带宽在预填充时处于闲置状态。Rubin CPX通过堆砌单Die算力，将单位功耗下的预填充吞吐量提升数倍，迫使超大规模数据中心重新评估其机架内部的算力配比：未来一个机架内，可能出现专攻预填充的CPX节点与专攻生成阶段的HBM（高带宽内存）增强型节点并存的异构设计。

产业链上游，台积电的3nm代工产能和先进封装技术将直接受益于单Die面积增大带来的良率挑战溢价。中游，光模块和交换机厂商面临压力——CPX的部署密度将推高单机架功耗至40kW以上，液冷散热的渗透率被迫从选配升级为标配。下游的云服务厂商，包括微软Azure和Meta等，则需在资本开支中重新分配预算：买更少的GPU但更贵的散热方案。

对中国市场而言，华为昇腾910C系列若仍坚持“训练推理一体”的通用架构，在推理侧的成本优势将被Rubin CPX的专用化路线侵蚀。A股光模块与液冷供应链将迎来二次分化，纯光模块标的的估值逻辑需要警惕，而能提供系统级散热方案的厂商将获得新的议价权。

**今日启示**：推理算力的专用化意味着GPU不再是一种通用商品，投资者需重新审视“囤卡”逻辑，关注数据中心散热与异构机架设计带来的结构性机会。

## 深度文章2：华为昇腾芯片的量产迷雾与HBM困局

**来源**：SemiAnalysis | **领域**：半导体/国产算力

华为昇腾芯片的生产进度，本质上是全球地缘政治挤压下的一场精密突围，而HBM是这场突围中最致命的瓶颈。据供应链信息，华为正通过“Die Bank”设计将多枚逻辑芯片拼接，试图在单芯片受限的情况下堆出等效算力。但这种方案牺牲了功耗和互联效率，最终系统成本远高于单一大尺寸芯片。

当前昇腾910C的制约因素不在于设计，而在于物理载体。HBM是AI芯片与内存之间的高速数据通道，目前全球98%的HBM产能由SK海力士和三星垄断，且严格受限出口管制。华为无法获得合规HBM，传闻中通过灰色渠道获取的三星HBM2E库存量级有限，且速率落后两代，直接导致昇腾集群在千卡级扩展时，内存墙效应急剧恶化——算力利用率可能跌至理论峰值的30%以下。

这使国产算力替代战略陷入一个尴尬的三角：先进逻辑芯片可通过台积电“影子产能”或中芯国际N+2工艺部分解决，但HBM封装涉及堆叠工艺和TSV（硅通孔技术——在芯片内钻微孔实现垂直互联，是HBM制造的核心壁垒），国内长鑫存储等厂商刚突破该技术的量产线，良率爬坡仍需至少18个月。在这段青黄不接的窗口期，大量规划中的智算中心面临“有机无芯”的风险，A股算力租赁板块的实际出租率和租金回报需重新检视。

赢家是能提供HBM替代路径的厂商。光互联方案厂商和存算一体芯片公司开始获得资本关注——它们提供的办法虽不能完全替代HBM，但在边缘推理侧能缓解部分带宽压力。输家则是单纯依赖昇腾芯片交付预期的下游整机厂，其估值逻辑的根基正在松动。

**今日启示**：国产算力的真正瓶颈不在流片，而在内存。紧盯长鑫HBM良率突破和长江存储的替代方案，这两家公司决定了A股算力叙事能否挺过2027年。

在产业链中，玻璃基板处于封装载板的最上游。当前CoWoS封装依赖的硅中介层，不仅造价高昂，且物理尺寸受限——12英寸晶圆的中介层最大面积固定，导致无法封装超过4枚以上大尺寸逻辑芯片。玻璃基板突破了这一物理天花板，单片基板面积可扩展至510mm×515mm以上，支持16枚及以上芯片的并行互联。这对英伟达Rubin Ultra、AMD MI500等下一代AI芯片的集成度提升至关重要。

竞争格局上，台积电此举对英特尔和三星的封装技术路线构成直接挤压。英特尔一直押注玻璃基板的代际优势，试图以此绕过台积电在CoWoS上的垄断，如今时间窗口收窄至不足两年。下游投资机遇分两条线：玻璃基板原材料供应商——康宁和日本旭硝子的高纯玻璃板材价格将被重新定价；而国内如沃格光电等刚完成玻璃基板中试线的A股公司，将面临技术验证与客户的加速认证窗口。

但风险同样鲜明：玻璃基板的钻孔和镀铜工艺是国内封测厂的集体短板。若无法在2027年前打通产业链配套，国内先进封装与台积电的差距将从当前的1.5代扩大至2代以上，届时A股封装龙头的估值溢价将消失。

**今日启示**：玻璃基板不是概念，而是有明确量产时间表的产业转折。关注能提供微孔加工和激光设备的A股供应商，其订单能见度将首先兑现。
